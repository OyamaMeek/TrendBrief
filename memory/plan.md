# 实施计划

以 Claude.md 为需求，用户已授权在当前仓库开发。

1. 建立固定依赖、真实 Trending 测试材料与解析/时间/分段测试，实现纯函数。
2. 实现有界 HTTP、README 获取、AI 摘要校验与 dry-run。
3. 实现严格状态校验、原子写入、Git 远端确认及 Telegram 保守恢复；用本地真实 Git 仓库验证失败阻止发送。
4. 固定官方 Actions SHA，配置三次调度、默认分支最新 checkout、串行发送与离线检查。
5. 完成使用及人工恢复文档，运行检查并提交推送；真实服务配置缺失时记录未验收范围。

接口约束：分段正文冻结后决定归档；状态和归档同一次提交成功 push 后才发送；sending 在远端确认后才发请求；sent 回存成功后处理下一段。
